# Bundle Editor（GUI06）

Bundle Editor は、アルゴリズムが誤った箇所を手で直すためのツールです。Image
Preprocessor（GUI01）が書き出したバンドルを 1 つ開き、解析の各段階の結果を
レイヤーとして重ねて表示します。マスク、スケルトン、キンクを編集し、編集した結果に
対して段階を 1 つずつやり直し、人が変更したことを記録した新しいバンドルとして保存
します。解析で書き出したバンドルに上書きすることはありません。細かな規則はすべて
README で説明しています。

![キンクの周りを拡大した Bundle Editor: 「キンクの編集」で選んだキンクが赤い丸で
囲まれ、角度を決める 2 本の腕が表示されている。上の行にはその内角が、右には
レイヤーの一覧がある。](images/gui06.ja.png)

## バンドルを開く

**バンドルを開く…** を押すか、Image Preprocessor（GUI01）の **GUI06で開く** を
押します。編集できるのは現在の形式のバンドルだけです。古い形式のバンドルは表示だけ
され、編集するには GUI01 で解析し直します。

いくつかのレイヤーには生の高さデータが必要です。バンドルがそれを持つのは、GUI01 で
**解析時に元データを保存** を付けていたときだけです。それ以外では、バンドルに記録
された入力ファイルから読みます。ただし、その名前のファイルがバンドルと同じフォルダに
あり、解析の後に変わっていない場合に限ります。読めないときは **元データ** の
レイヤーが無く、**リッジマスクの検出** と **背景補正** はやり直せません。

## レイヤー

右のレイヤーの一覧には、上から順に **キンク**（キンク規則が測ったが判定しなかった
折れは中抜きの印で描きます）、**中心線**、**細線化画像**、**二値化画像**、
**リッジマスク**、**背景補正画像**、**元データ** が並びます。

- 各行のチェックボックスでレイヤーの表示・非表示を、スライダーで不透明度を
  切り替えます。**二値化画像**、**リッジマスク**、**元データ** は最初は非表示です。
- 行をドラッグすると、重ねる順が変わります。
- 「古い」と付いたレイヤーは、元になるレイヤーが変わった後、その段階をやり直して
  いません。

マウスホイールで拡大・縮小し、右ボタンまたは中ボタンのドラッグで表示を動かします。
**全体を表示** で画像全体の表示に戻ります。

## 編集する

レイヤーの名前をクリックすると、そのレイヤーを編集できます。編集できるのは
**キンク**、**細線化画像**、**二値化画像**、**リッジマスク** で、ほかのレイヤーは
表示だけです。使えるツールはレイヤーによって違います。

| レイヤー | ツール |
|---|---|
| **リッジマスク**、**二値化画像** | **鉛筆** はドラッグした画素を加え、**消しゴム** は除く。 |
| **細線化画像** | **消しゴム** だけ（線の太さを 1 画素に保つため）。 |
| **キンク** | **キンク追加**、**キンク消去**、**キンク移動**、**キンクの編集**。 |

- **ブラシの太さ (px)** で、鉛筆と消しゴムの太さを 1〜99 画素の間で決めます。
- キンクは繊維の細線化画素の上に置きます。**キンク消去** は中抜きの印（判定しなかった
  折れ）も消します。
- **キンクの編集**: キンクをクリックすると、その角度を決める 2 つの端点が赤で表示
  され、細線化画素に沿ってドラッグできます。解析が見つけたキンクは、端点のどちらかを
  動かすまで解析の角度を保ち、そのあいだ端点は破線で描かれます。
- **元に戻す**（Ctrl+Z）と **やり直す**（Ctrl+Y）で変更をたどれます。
  **表示のみ** を選ぶと、クリックしても何も変わりません。

## 段階をやり直す

**再実行** の後のボタンは、今の結果に対して段階を 1 つやり直します。

| ボタン | 何から計算するか |
|---|---|
| **リッジマスクの検出** | 元データ。 |
| **背景補正** | 元データと、今のリッジマスク（方式が `tophat` のときはマスクを使わない）。 |
| **二値化** | 背景補正画像。 |
| **細線化** | 二値化画像。 |
| **キンク検出** | 細線化画像と背景補正画像。 |

**背景補正** と **二値化** の横の **設定…** で、その段階の設定を変えられます。
手で変更した結果を置き換える段階は、実行する前に確認します（**元に戻す** で変更を
取り戻せます）。

## 保存する

- **名前を付けて保存…**（Ctrl+Shift+S）は、バンドルとその `_param.json` を、指定
  した名前で保存します。既定の名前は、開いたバンドルの名前の後に `_edited` を
  付けたものです。保存した後、そのバンドルを開き直します。
- **上書き保存**（Ctrl+S）は、開いているバンドルが編集済みのもので、変更があるときに、
  確認してから上書きします。解析で書き出したバンドルを開いているときの Ctrl+S は
  **名前を付けて保存…** を開きます。
- **編集者（任意）** に入れた名前は、編集した人として保存するバンドルに記録されます。
- 「古い」と付いたレイヤーが残っていても、確認のうえで保存できます。どのレイヤーが
  古いかはバンドルに記録されます。

保存したバンドルは、ほかのツールや `cli.py` が普通のバンドルと同じように読みます。
**ログを保存** でログをテキストファイルに保存できます。
