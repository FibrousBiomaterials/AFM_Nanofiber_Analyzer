# Fiber Tracker（GUI04）

Fiber Tracker は、バンドル内のすべての繊維を計測値とともに一覧にし、各繊維を高さ像の
上に示します。Fiber Morphology Statistics（GUI03）で集計する前に、ここで繊維を
整理できます（断片を 1 本のフィブリルに連結し、不要な物体を除外します）。各値の
計算方法は [gui04_measurements.ja.md](../gui04_measurements.ja.md) で、細かな規則は
README で説明しています。

![バンドルを開いた Fiber Tracker: 各繊維の値を並べたファイバー一覧と、すべての繊維に
番号と枠を付けた高さ像。選んだ繊維は黄色い枠で示されている。](images/gui04.ja.png)

## バンドルを開く

**📂 ファイルを開く** を押すか、Image Preprocessor（GUI01）や Thumbnail Viewer
（GUI05）の **GUI04で開く** を押します。一度に開けるバンドルは 1 つで、ウィンドウの
タイトルにその名前が出ます。**スケール (µm)** にはバンドルに記録された走査範囲が
入ります。ここに別の大きさを入れると、長さはその大きさで計測され、そのことがログに
出ます。

## ファイバー一覧と全体像

**ファイバー一覧** の 1 行が 1 本の繊維です。列見出しにマウスを乗せるとその値の説明が
出て、**計測値の説明** ですべての値の説明を一覧できます。長さの前の `≥` は下限値で
あることを示します。その繊維は、走査範囲の端や切断箇所で、計測した範囲の外へ
続いています。

行を選ぶと、**AFM 全体像** でその繊維が枠で示されます。Shift+クリックで範囲を、
Ctrl+クリックで 1 本ずつ選択に加えられます。

- **高さ** / **ファイバー色分け** で全体像の描き方を選びます。
- **自動**、**vmin**、**vmax** で色の範囲を、**フォントサイズ** の欄で文字の大きさを
  決めます。
- 全体像の下のツールで、全体像を移動・拡大できます。**リセット** で画像全体に戻り、
  **選択へズーム** で選んだ繊維が画面いっぱいになるまで拡大します。**番号・枠** で
  繊維の番号と破線の枠の表示を切り替えます（選んだ繊維の黄色い枠は消えません）。
- **画像を保存** は、拡大した状態も含めて、描かれているとおりの全体像を保存します。
- **個別表示** は、選んだ繊維を専用のウィンドウで開きます。中心線とキンクを重ねた
  拡大画像と、高さプロファイルのウィンドウがあり、それぞれに表示の設定と
  **画像を保存** があります。
- **CSVで保存** は、一覧にある繊維の値を保存します。

**高さフィルター** は、各繊維のうち高さが **最小** と **最大**（nm）の間にある区間
だけを残します。チェックを付けたり外したりすると、すぐに反映されます。

## 断片をつなぐ（連結）

スケルトンは交差や分岐で分かれるので、1 本のフィブリルがいくつかの断片として並ぶこと
があります。これらはつなげられます。

| ボタン | 動作 |
|---|---|
| **自動連結** | 位置・向き・高さが続いている断片を探し、つなぎます。結果は保持されます。既に連結がある場合は、置き換えてよいかを確認します。 |
| **自動連結の設定** | 探索のしきい値。次に **自動連結** を押したときに使われます。 |
| **手動で連結** | 選んだ繊維の端の近くにある連結先の候補を、自動連結の条件を満たすかどうかと一緒に並べ、選んだ相手とつなぎます。 |
| **連結を解除** | すべての連結部を一覧し、選んだものを全体像で示して、それだけ、またはすべてを解除します。 |
| **元に戻す** | 直前の連結の操作（自動連結、手動連結、連結の解除）を 1 つ元に戻します。 |

## 繊維を除外する（除外）

| ボタン | 動作 |
|---|---|
| **選択を除外** | 選んだ繊維を、一覧・全体像・CSV から外します。 |
| **非孤立を除外** | 全長を計測できなかった繊維をまとめて除外します。ほかの繊維に接している繊維、走査範囲の端に達している繊維、連結器が続きを見つける繊維です。先にすべての連結を解除してください。密な試料では残る繊維がわずか、または 0 本になることがありますが、それが結果であり、不具合ではありません。 |
| **直前を取消** | 最後の除外を取り消します。続けて押すと、さらにさかのぼります。 |
| **範囲で選択** | 全体像の上で矩形をドラッグすると、それにかかる繊維をすべて選びます（Ctrl で選択に追加、Esc で取りやめ）。枠を確かめてから **選択を除外** を押します。 |
| **除外設定** | 除外を一覧し、任意の 1 件またはすべてを元に戻します。 |

## 整理の結果を保存する

**除外・連結を保存** は、除外と連結をまとめて、バンドルの横の
`<バンドル名>_excluded.json` と `<バンドル名>_connect.json` に書き出します。
Fiber Morphology Statistics はこの 2 つのファイルを読む（**除外を適用** と
**連結を適用**）ので、このウィンドウに見えているのと同じ繊維を集計します。このボタンは
未保存の変更があるときだけ押せます。未保存の変更があるままバンドルを離れようとすると、
保存するかどうかを確認します。

**ログを保存** でログをテキストファイルに保存できます。
