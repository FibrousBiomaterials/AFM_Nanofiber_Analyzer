# Format Converter（GUI00）

Format Converter は、このソフトが読めない形式の AFM ファイルを Gwyddion の
`.gwy` ファイルに変換します。変換したファイルは Image Preprocessor（GUI01）で
解析します。GUI01 が読むのはテキスト出力（`.txt`）と `.gwy` ファイルなので、
装置独自の形式でしか保存していないスキャンは、先にここで変換します。

![フォルダを変換した後の Format Converter: 状態「変換しました」と読み込んだ
Gwyddion モジュールが表示された 2 つのファイルと、実行のログ。](images/gui00.ja.png)

例のフォルダには、`testdata/` に同梱したスキャンから書き出した 2 つの
Gwyddion Simple Field（`.gsf`）ファイルが入っています。

## 準備

変換では、任意パッケージ `gwyddionpy-converter` に含まれるプログラム
`gwyconvert` を通して、Gwyddion のファイル読み込み機能を使います。起動スクリプト
`run_venv` と `run_conda` がこのパッケージをインストールし、インストールできない
ときはメッセージを表示します。それ以外の方法で用意した環境では、次のコマンドで
インストールしてください。

```
python -m pip install "gwyddionpy-converter>=0.1.0,<0.2"
```

インストールしていなくてもウィンドウは開き、**変換開始** を押すとこのコマンドが
表示されます。

## 手順

1. ランチャーから **Format Converter** を起動します。
2. **フォルダを選択** を押し、測定ファイルの入ったフォルダを選びます。フォルダの
   直下にあるファイルのうち、拡張子が `.txt`、`.csv`、`.gwy`、`.b2z`、`.json`、
   `.npy` のもの（このソフト自身が読み書きするもの）を除いたすべてが一覧に並び
   ます。変換後の `.gwy` が既にあるファイルは **変換済み（.gwy あり）** と表示され
   ます。
3. **変換開始** を押します。各ファイルは同じフォルダの
   `<元のファイル名>_converted.gwy` に変換されます。たとえば `scan.ssp` は
   `scan.ssp_converted.gwy` になります。表には各ファイルの結果と、読み込んだ
   Gwyddion モジュールが表示され、ログの最後に、変換した件数、省略した件数、
   変換できなかった件数が出ます。
4. **GUI01で開く** を押すと、そのフォルダが Image Preprocessor で開きます。
   GUI01 はフォルダ内の `.txt` と `.gwy` ファイルをすべて並べるので、変換した
   ファイルもその中に入ります。フォルダを選んでいないとき、および変換の実行中は
   このボタンを押せません。

## 結果の表示

| 状態 | 意味 |
|---|---|
| **未変換** | 一覧に並んでいて、このウィンドウではまだ変換していない。 |
| **変換しました** | `.gwy` ファイルを書き出した。 |
| **変換済み（.gwy あり）** | `.gwy` ファイルが既にあったので、変換を省略した。 |
| **変換できませんでした** | `.gwy` ファイルは書き出していない。理由は **詳細** の列とログに出る。 |

変換したファイルは、長さの単位を持つチャンネルを含む場合にだけ残します。
Gwyddion は PNG のスクリーンショットのような普通の画像も開けるため、そのままでは
それが高さ像として解析されてしまうからです。そのようなファイルは
**変換できませんでした** となり、理由に「no channel with a length unit」と出ます。
変換に失敗したときは `.gwy` ファイルが残らないので、次に実行したときにもう一度
変換を試みます。

**ログを保存** でログをテキストファイルに保存できます。コマンドラインからは
`cli.py convert` で同じ変換を実行できます。
