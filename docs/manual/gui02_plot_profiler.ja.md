# Plot Profiler（GUI02）

Plot Profiler は、AFM の高さ像の上に引いた線に沿って高さプロファイルを取り出します。
たとえば繊維に沿った高さや、繊維を横切る断面の高さを見るのに使います。

![バンドルを開いた Plot Profiler: 高さマップ上で繊維に沿って置いた点と、それらを
結ぶ線に沿った高さプロファイル。](images/gui02.ja.png)

## ファイルを開く

**参照** を押してファイルを選ぶか、Image Preprocessor（GUI01）や Thumbnail
Viewer（GUI05）の **GUI02で開く** でバンドルを直接開きます。Plot Profiler が
読むのは次のファイルです。

- `.b2z` バンドル（背景補正後の高さ `calibrated` を表示します）
- `.npy` 配列、テキストや CSV の出力（`.txt`、`.csv`）
- Gwyddion の `.gwy` ファイル。チャンネルが複数あるファイルでは、**チャンネル** で
  表示するものを選びます。

**スケール (µm)** の X と Y には走査範囲が入ります。バンドル、ファイルのヘッダ、
`.gwy` のチャンネルから自動で入ります。走査範囲を記録していないファイル（たとえば
`.npy` 配列）では、入力欄にあった値がそのまま残るので、計測の前にその大きさを入力して
ください。Y が空欄なら正方形の走査（Y = X）です。**µm** / **nm** のボタンは、軸の
目盛の単位を切り替えるだけです。

## プロファイルを取る

1. 高さマップの上で右クリックして最初の点を置き、続けて右クリックで点を足していき
   ます。2 点目からは、すべての点を結ぶ線に沿ったプロファイルが右側に描かれます。
2. **一点取り消し** で最後の点を消し、**全点取り消し** ですべての点を消します。
3. 高さマップの下のツールで、マップを移動・拡大できます。**リセット** で画像全体の
   表示に戻ります。

プロファイルの各高さは次のように求めます。

- 各標本は、それを含む画素の値をとります。画素の間を補間した高さは使いません。
- **線幅（ピクセル）** は奇数の画素数です。標本は線の上に 1 つと、その両側に
  整数画素ずつ並びます。この幅は高さマップ上に青い帯で示されます。
- 線幅が 1 より大きいときは、線を横切る方向の標本を **計算方法** でまとめます。
  **最大**（繊維の頂上を拾う）、**最小**（背景の高さを見る）、**平均**（ノイズを
  ならす）から選びます。画像の端より外にある標本は除きます。

**自動**、**vmin**、**vmax** で高さマップの色の範囲を決めます。**フォントサイズ** の
欄は高さマップの文字の大きさを決め、そのうち **軸ラベル** と **軸目盛** の大きさは
プロファイルの図にも使われます。入力欄の値は Enter を押すと反映されます。

## 保存する

| ボタン | 保存するもの |
|---|---|
| **画像を保存**（高さマップの下） | 線を引いた高さマップ。 |
| **csvで保存** | プロファイル。列は `Length`（軸の単位）と `Height (nm)`。 |
| **画像を保存**（プロファイルの下） | プロファイルの図。 |
| **レイアウト調整してグラフ作成** | 幅、高さ、軸ラベルと目盛の大きさ、目盛の向き、グリッドを選んでプロファイルを描き、保存できるウィンドウを開く。 |

これらのボタンを押さない限り、何も書き出しません。
