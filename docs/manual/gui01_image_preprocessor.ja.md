# Image Preprocessor（GUI01）

Image Preprocessor は AFM の高さ像を解析します。各スキャンに背景補正、二値化、
細線化、キンク検出を行い、結果を `.b2z` バンドルとして保存します。ほかのツールは
すべてこのバンドルを読みます。各段階が何を計算し、各設定が何を変えるかは
[algorithms.ja.md](../algorithms.ja.md) で説明しています。

![2 つのスキャンを入れたフォルダを解析した後の Image Preprocessor: ファイルごとの
走査範囲を持つファイル一覧と、選んだスキャンの Original・Calibrated・Binarized・
Skeletonized の画像、およびキンク点の重ね表示。](images/gui01.ja.png)

## フォルダを開く

ランチャーから **Image Preprocessor** を起動し、**フォルダ選択** を押します。
フォルダの直下にある `.txt` と `.gwy` ファイルがすべてファイル一覧に並びます。
GUI00 の **GUI01で開く** でも同じようにフォルダが開きます。

ファイル一覧には 1 ファイルにつき 1 行が並びます。

| 列 | 内容 |
|---|---|
| **ファイル名** | 入力ファイル。このセルを選ぶと、そのファイルがプレビューに表示される。 |
| **X (µm)**、**Y (µm)** | 走査範囲。編集できる（後述）。 |
| **縞ノイズ率** | フィードバック不良でずれた走査線の割合（後述）。 |
| **走査線範囲** | 解析する走査線。編集できる。空なら画像全体。 |
| **状態** | **未解析**、**解析中**、**解析済み** のいずれか。 |
| **処理時間 (s)** | 最後の解析にかかった秒数。 |

バンドルが既にあるファイルは **解析済み** と表示されます。

## 走査範囲を設定する

このソフトが出す長さはすべて走査範囲から計算するので、どのファイルも解析の前に
走査範囲が必要です。フォルダを開くと自動で入ります。解析済みのファイルではバンドル
から、それ以外ではファイルのヘッダ（島津の出力の `SizeX` / `SizeY`、Gwyddion の
テキスト出力のサイズのコメント、`.gwy` ファイルのチャンネルの大きさ）から読み
ます。どちらも無いファイルは空欄のまま残り、その件数がログに出ます。

手で設定するには、次のいずれかを使います。

- **X (µm)** と **Y (µm)** のセルに入力するか、表計算ソフトから値の列を貼り付け
  ます。Y が空欄なら正方形の走査（Y = X）として扱います。
- 一覧の下の入力欄に X と Y を入れ、**選択ファイルに適用** または
  **全ファイルに適用** を押します。
- **スケール表(CSV)読込** を押し、CSV ファイルを選びます。CSV にはヘッダ行と
  `filename` 列、さらに `scale_um` 列か、`scale_x_um` と `scale_y_um` の 2 列が
  必要です。ファイル名は拡張子があってもなくても一致します。例:

  ```
  filename,scale_x_um,scale_y_um
  TunicateACTOCCNF.txt,5,5
  ```

解析するファイルに走査範囲の無いものがあると、解析は始まらず、エラーにそのファイルが
並びます。

## 解析する

1. **設定** を押して解析の設定を確かめます（次の節）。多くのスキャンは既定値の
   ままで解析できます。
2. **全て解析** を押すか、行を選んで **解析** を押します。
3. ログの下の進捗バーに、解析中のファイルと段階が表示されます。**停止** を押すと、
   解析中のファイルが終わったところで止まります。

**解析済みを上書き** を外していると、解析済みのファイルは飛ばされ、そのことが
ファイルごとにログに出ます。付けていると、もう一度解析します。

解析するたびに、入力ファイルの横に 2 つのファイルが書かれます。

- `<拡張子を除いた入力ファイル名>.b2z`: 解析結果を持つバンドル。
- `<拡張子を除いた入力ファイル名>_param.json`: 解析に使った設定。

各ファイルの解析後、ログに警告が出ることがあります。背景補正が繊維の高さを低くした
可能性があるという警告（代わりに試す設定も示します）と、画素ノイズが繊維の高さに
対して大きいという警告です。どちらの警告も README で説明しています。

## 設定

![設定ダイアログ: 段階ごとにまとめた解析の設定とその説明。選んだ背景補正の方式が
使わない設定は灰色になっている。](images/gui01_settings.ja.png)

**設定** を押すと、段階ごとにまとめた解析の設定が開きます。変更は次の解析から
反映されます。選んだ `bg_method` が使う設定だけが編集でき、それ以外は灰色に
なります。

| ボタン | 動作 |
|---|---|
| **設定の保存** | 設定を JSON ファイルに保存する。 |
| **設定の読み込み** | JSON ファイルから設定を読み込む。バンドルの横に書かれる `_param.json` もこの形式なので、前の解析と同じ設定で解析し直せる。 |
| **現在値を既定値として保存** | 今の値を、ウィンドウを開いたときの値にする（先に確認する）。 |
| **初期値に戻す** | ダイアログのすべての値をソフトの初期値に戻す（先に確認する）。ウィンドウを開いたときの値が変わるのは **現在値を既定値として保存** を押したときだけ。 |

このダイアログには、フィードバック不良とみなす段差の高さ（**縞ノイズの判定**）と、
背景補正前の生の高さ像もバンドルに保存する **解析時に元データを保存** もあります。

## 結果を見る

**ファイル名** の列のセルを選ぶと、そのファイルが右側に表示されます。生の画像
（**Original**）、背景補正後の高さ（**Calibrated**）、二値化した繊維
（**Binarized**）、スケルトン（**Skeletonized**）の 4 枚です。

- **重ね表示** で、スケルトン上に点を重ねます。端点（`EP`、青）、分岐点（`BP`、
  赤）、キンク点（`KP`、シアン）、分解点（`DP`、オレンジ）から選びます。
- **vmin** と **vmax** で色の対応する高さの範囲を決めます。**タイトル表示**、
  **スケール表示**、**軸目盛単位**、**フォントサイズ…** で図の見た目を変えます。
- **画像を保存** は 4 枚を並べたプレビューを保存します。**個別表示** は 1 つの
  段階を、色の範囲も別に持つ専用のウィンドウで開きます。

## 縞ノイズのあるスキャン

顕微鏡のフィードバックが一時的に外れると、走査線がまるごとずれます。解析のいくつかの
段階は画像全体の統計からしきい値を決めるので、このような帯が 1 本あるだけで、画像の
ほかの部分の検出にも影響することがあります。フォルダを開くと、すべてのスキャンを
これについて検査します。

- **縞ノイズ率** に、影響を受けた走査線の割合が出ます。少しでもあるスキャンは色付きで
  表示されます。
- ログに、縞ノイズの無い走査線の範囲が出ます。
- 影響を受けた走査線は **Original** の画像にシアンで示されます。

この検査は報告するだけで、解析する内容は何も変えません。乱れた走査線を除くには、
きれいな範囲だけを解析します。

![縞ノイズで分割した後のファイル一覧: 高等植物のスキャンが、走査線 0-817 と
834-1024 の 2 つの項目に分かれ、どちらも未解析になっている。Original の画像には
影響を受けた走査線が示されている。](images/gui01_split.ja.png)

1. スキャンを選んで **縞ノイズで分割** を押します。何も選んでいなければ、縞ノイズの
   あるすべてのスキャンを分割します。きれいな範囲がそれぞれ 1 つの項目になり、
   **走査線範囲** にその範囲が、Y にその範囲の大きさが入ります。
2. 必要なら **走査線範囲** のセルを編集して範囲を調整します。走査線は 0 から数え、
   `473-696` は 473 行目から 695 行目までです。複数の範囲はカンマで区切り、重ねては
   いけません。空のセルは画像全体を解析します。
3. 項目を解析します。各範囲はそれぞれ 1 枚の画像として解析され、
   `<拡張子を除いた入力ファイル名>_r<開始>-<終了>.b2z` として保存されます。

**分割を解除** を押すと、項目は画像全体の 1 項目に戻ります。分割した項目が作った
バンドルを削除するかどうかを確認します（既定は残す）。

## 結果をほかのツールで開く

| ボタン | 開くもの |
|---|---|
| **GUI02で開く**、**GUI04で開く**、**GUI06で開く** | プレビューに表示中のバンドルを、Plot Profiler、Fiber Tracker、Bundle Editor で開く。 |
| **GUI03で解析** | Fiber Morphology Statistics を開き、フォルダ内のすべてのバンドルを最初のグループに登録する。 |
| **GUI05で開く** | Thumbnail Viewer を開き、フォルダ内のすべてのバンドルを表示する。 |
| **出力先を開く** | フォルダをファイルマネージャーで開く。 |

押すたびに新しいウィンドウが開きます。解析の実行中はどのボタンも押せません。
一覧の上の 2 つは解析済みのファイルが無いとき、プレビューの上の 3 つはプレビューに
何も表示していないときに押せません。

**ログを保存** でログをテキストファイルに保存できます。コマンドラインからは
`cli.py process` で同じ解析を実行できます。
