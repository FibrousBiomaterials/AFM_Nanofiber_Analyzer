# Fiber Morphology Statistics（GUI03）

Fiber Morphology Statistics は、バンドルのグループの間で、繊維の 1 つの量の分布を
比べます。1 つのグループは 1 つの試料を表し、その中のバンドルはまとめて集計されます。
1 つの標本が何か、各統計量の計算方法、各検定が従う公表された手法は
[gui03_statistics.ja.md](../gui03_statistics.ja.md) で、細かな規則は README で説明
しています。

要約統計量、およびグループ一覧の下に表示した、選択中のバンドルの補正後画像。](images/gui03.ja.png)

## バンドルを登録する

ランチャーから **Fiber Morphology Statistics** を起動します。Image Preprocessor
（GUI01）の **GUI03で解析** や Thumbnail Viewer（GUI05）の **GUI03で開く** で
開くと、それぞれのバンドルが最初のグループに登録された状態で始まります。

- **グループ追加** でグループを足し、**グループ削除** で選んだグループを消します。
  **↑** / **↓** で並べる順を変えます。
- **ファイル追加** で、選んだグループにバンドルを加えます（ダイアログでは複数の
  ファイルを一度に選べます）。**ファイル削除** は選んだファイルを一覧から外し、
  **全クリア** はすべてを外します。ファイル自体はそのまま残ります。
- グループを右クリックすると、**名前を変更** と **色を変更** ができます。ファイルの
  行は、別のグループへドラッグするか、右クリックの **グループへ移動** で移せます。
- ファイルの行を選ぶと、そのバンドルの補正後の高さ像が一覧の下に表示されます。

**除外を適用** と **連結を適用** にチェックが付いていると（既定）、Fiber Tracker
（GUI04）で保存した除外と連結が適用され、そこに見えていたのと同じ繊維を集計します。

## 比べるものを選ぶ

| 項目 | 選ぶもの |
|---|---|
| **計測量** | `height`、`contour length`、`straightness`、`curvature`、`kink density`。 |
| **集計単位** | 1 つの標本を何とするか。`pixel`（スケルトンの 1 画素。`height` のみ）、`fiber`（1 本の繊維）、`image`（1 スキャン）。計測量ごとに使える単位だけが並びます。 |
| **図** | `histogram`、`ECDF`、`box`。 |
| **曲率窓 (nm)** | `curvature` を測る弧の長さ。これより短い繊維は除かれ、その本数がログに出ます。 |
| **枠のファイバー** | `contour length` で、走査範囲の端に達する繊維の扱い。`include`、`exclude`、`Miles-Lantuejoul`、`Kaplan-Meier`。 |

**最小**、**最大**、**ステップ** でヒストグラムの範囲と階級の幅を決めます。**Y** は
縦軸の種類で、`density`、`percent`、または **非表示**（生の度数を描き、縦軸の目盛を
出さない）から選びます。範囲の外にある標本はログに出ますが、統計量は常にすべての
標本から計算します。**表示** でグループを縦に並べるか（**縦並び**）、1 つの軸に
重ねるか（**重ね表示**）を選び、**統計値表示** で図の中に要約統計量を書き込みます。
**図の幅**、**図の高さ** と **フォントサイズ** の欄で図の大きさと文字を決めます。

## グラフを作る

**グラフ作成** を押します。**中止** を押すと、計測中のバンドルが終わったところで
止まり、図と統計値は更新されません。グラフを作った後にグループを変えると、作り直しが
必要であることがボタンの横に表示されます。**画像を保存** で図を、**数値を保存** で
各グループの標本の値を CSV ファイルに保存します。

## 統計値と群間比較

![統計処理のウィンドウ: 上に各グループの要約統計量、その下に 2 つのグループの
比較と注記がある。](images/gui03_stats.ja.png)

**統計処理** を押すと、2 つの表を持つ専用のウィンドウが開きます。

- 各グループの要約統計量（中央値、四分位範囲、平均、標準偏差、最頻値、および標本・
  繊維・画像の数）。**統計値を保存** で保存します。
- すべてのグループの組の比較（主検定は Mann-Whitney U、参考値として
  Kolmogorov-Smirnov、効果量は Cliff の delta）。**比較を保存** で保存します。

比較の表の下の注記に、結果の読み方が書かれます。検定は集計単位が `fiber` と `image`
のときだけ行い、`image` ではグループごとに 3 スキャン以上が必要です。このウィンドウを
開いたままグラフを作り直すと、内容が更新されます。

**ログを保存** でログをテキストファイルに保存できます。
